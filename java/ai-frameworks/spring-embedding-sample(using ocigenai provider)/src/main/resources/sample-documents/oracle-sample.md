# Oracle Dependency Sample

This file is loaded by `OracleDocumentReader` from the consumer module.

The sample demonstrates:
- Loading documents with `OracleDocumentReader`
- Splitting with `DocumentSplitter`
- Embedding with `OracleEmbeddingModel` (provider can be `ocigenai`)
- Storing and searching vectors with `OracleVectorStore`

If you can read this text from similarity search results, the dependency-based setup is working.
